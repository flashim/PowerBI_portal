08 — Security Guidelines

Mandatory
 - HTTPS everywhere
 - No secrets in frontend
 - Rotate SP secrets every 90 days
 - Validate B&E JWT on each request
 - Implement tenant-level RBAC
 - Enable Power BI audit logs
 - CSP headers for iframe embedding

Optional
 - VNet integration
 - Azure Front Door WAF
 - Key Vault for secret storage
